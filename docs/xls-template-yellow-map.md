Это рабочий документ для проверки с тобой. Здесь не все поля уже подтверждены, но каркас для внедрения готов.

## Где это подключается

- Сам файл-шаблон кладется в [assets/templates/Templates](C:/Users/mihd0/Downloads/Вова/assets/templates/Templates).
- Логика автоподстановки для `.xls` реализуется в [document_generator.py](C:/Users/mihd0/Downloads/Вова/backend/app/services/document_generator.py).
- Доступные общие поля уже собираются в [document_context.py](C:/Users/mihd0/Downloads/Вова/backend/app/services/document_context.py).

## Что уже есть в системе

Из текущего кода уже можно брать без новой модели:

- `ClientCalc` — ФИО
- `BirthDateCalc` — дата рождения
- `VisitDate` — дата обращения
- `AddressCalc`, `CityCalc`, `StreetCalc`, `HouseNumberCalc`, `ApartmentNumberCalc` — адрес
- `Phone` — телефон
- `SNILS` — СНИЛС
- `PolisOMS` — полис ОМС
- `DocumentSeries`, `DocumentNumber`, `DocumentDate`, `WhoGive` — паспортные данные
- `CompanyName`, `Post` — организация и должность
- `Diagnosis`, `Doctor` — итоговые поля
- `Services` — услуги
- `ReferenceNumber` — номер обращения / клиента
- `BlankNumber`, `BlankSeries`, `BlankFullNumber` — номерные бланки

## Что проверить глазами

- Где желтая ячейка действительно должна заполняться из системы.
- Где в желтом сейчас просто пример врача, а не данные пациента.
- Какие поля должны браться из осмотров, а не из карточки клиента.
- Какие листы реально используются в работе, а какие можно не подключать.
